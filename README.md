# 🎬 MovieTicketBooking – iOS App

A modern **Movie Ticket Booking iOS application** built using **Swift and UIKit**.
This project demonstrates a complete movie booking flow, including movie discovery, show selection, seat selection, and booking/payment UI.

## 🚀 Features

* 🎥 Movie Listing & Movie Details
* 🔍 Movie Search
* 📅 Show Date & Time Selection
* 💺 Interactive Seat Selection
* 🎟️ Complete Ticket Booking Flow
* 💳 Booking & Payment UI
* 📱 Responsive UI using UIKit
* 🧭 Smooth Navigation & Screen Transitions
* 🌐 REST API Integration
* 🔥 Firebase Integration

## 🛠️ Tech Stack

* **Language:** Swift
* **UI Framework:** UIKit
* **UI Design:** Storyboard / XIB
* **Layout:** Auto Layout
* **Networking:** REST API
* **Data Parsing:** JSON / Codable
* **Architecture:** MVC
* **Backend Services:** Firebase
* **IDE:** Xcode

```text
Onboarding
    ↓

    ↓

    ↓
Payment UI
    ↓
Booking Confirmation
```
